# Publicação da demonstração

Hospedagem: Vercel. Repositório sugerido: `evliza`, privado, na conta pessoal do GitHub.

## Configuração na Vercel

- Framework Preset: Next.js.
- Root Directory: raiz do repositório (`./`).
- Install Command: padrão (`npm install`); package-lock.json deve entrar no Git.
- Build Command: `npm run build`.
- Output Directory: padrão do Next.js; não configurar `out`.
- Environment Variables: nenhuma necessária.
- Plano: Hobby para demonstração pessoal não comercial, dentro dos limites do serviço.

## Passos

1. Criar repositório privado `evliza` no GitHub, sem README, licença ou gitignore gerados pelo GitHub.
2. Fazer o primeiro commit local, configurar o remote e enviar a branch main.
3. Em https://vercel.com/new, importar esse repositório da conta pessoal.
4. Manter o preset Next.js e clicar Deploy.
5. Conferir a URL de produção em uma janela anônima e percorrer toda a jornada.
6. Para permitir acesso de visitantes, conferir Deployment Protection e assegurar que a URL de produção abre sem login da Vercel.

## Revisão antes do LinkedIn

Abrir a home, reservar, iniciar, devolver, responder feedback, conhecer benefício, solicitar proposta e simular aprovação. Conferir mobile e atualizar a página para verificar a retomada.

Cada visitante usa dados simulados e o estado do próprio navegador. O painel continua sendo uma coorte fictícia. Não há backend, pagamento, contrato, credenciais ou banco de dados a configurar.

O site mantém os avisos de protótipo independente e dados simulados. A configuração de robots desabilita indexação; a URL pode ser compartilhada normalmente.

Para gravar, usar Reiniciar demonstração no topo e seguir pelos botões das telas. O roteiro está no README.
